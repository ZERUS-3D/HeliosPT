# Перенос разработки HeliosPT в приложение Kimi — пошагово

## Шаг 1. Скачай актуальную версию шейдера

На сайте-дашборде нажми **«Скачать ZIP»** (файл `HeliosPT.zip`).
В нём: папка `shaders/` (весь код) и документы `INSTALL.md`, `HANDOFF.md`,
этот файл в корне. Распакуй архив в отдельную папку — понадобится
прикладывать отдельные файлы.

## Шаг 2. Сними логи с текущей версии

1. Положи свежий `HeliosPT.zip` в `.minecraft/shaderpacks/` (старый удали).
2. Запусти Minecraft ПОЛНОСТЬЮ (не Reload Shaders), зайди в мир, включи пак.
3. Закрой игру.
4. Возьми `.minecraft/logs/latest.log`.
5. Если можешь — сделай скриншот F2 сразу после включения пака в мире
   (по нему видно: ваниль это или шейдеры).

Если лог огромный, в текстовом редакторе найди и скопируй ВСЕ строки вокруг:
- `Creating pipeline for dimension`
- `Failed to create shader rendering pipeline`
- `Couldn't compile`
- `[Oculus]` (все строки с этим тегом от момента выбора пака)
- любой `ERROR` после `Creating pipeline`

## Шаг 3. Начни новый диалог в Kimi

Приложи к первому сообщению:
1. `HeliosPT.zip` целиком (Kimi умеет читать архивы; если нет — прикладывай
   файлы по списку из HANDOFF.md, раздел 5).
2. `latest.log`.
3. Скриншот, если есть.

Затем вставь промпт ниже (можно без изменений).

## Шаг 4. Как передавать файлы, если Kimi не читает ZIP

По очереди пришли содержимое (это покрывает 90% вопросов компиляции):
`HANDOFF.md` → `shaders.properties` → `shaders/lib/options.glsl` →
`shaders/lib/voxel.glsl` → `shaders/shadow.vsh`, `.gsh`, `.fsh` →
`shaders/gbuffers_terrain*.vsh/.fsh` и общий `lib/gbuffers_terrain_shared.glsl`
→ `composite.fsh`, `composite1.fsh`, `composite2.fsh`, `composite3.fsh`,
`final.fsh` → затем остальные библиотеки.

## Шаг 5. Рабочий цикл (важен!)

1. ИИ правит файл → ты заменяешь его в папке `shaders/`.
2. Пересобираешь ZIP: зайди ВНУТРЬ папки `HeliosPT_Shader`, выдели папку
   `shaders` (+ при желании .md в корень), ПКМ → «Отправить → Сжатая
   ZIP-папка». В корне архива должна быть видна сразу `shaders/`.
   Либо на сайте-дашборде кнопка «Скачать ZIP» собирает всё автоматически.
3. Клади в `shaderpacks/`, ПОЛНЫЙ перезапуск Minecraft.
4. Сохраняй `latest.log` ПОСЛЕ каждой итерации (лог перезаписывается при
   каждом запуске — копируй его сразу после выхода).
5. Отправляй лог + скриншот, получай следующую правку.
